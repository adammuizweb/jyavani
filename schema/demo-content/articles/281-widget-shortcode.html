Jyavani membedakan widget area, Theme Zone gadget, shortcode konten, dan shortcode preset. Masing-masing dirender pada tahap yang berbeda.

Sidebar dan Theme Zones

Sidebar zone berisi item seperti search, recent posts, HTML, atau preset. Theme Zones menempatkan gadget pada posisi yang dideklarasikan theme, termasuk navigation, image, rich text, pages, social, search, dan metadata post. Ketersediaan tampilan bergantung pada theme yang benar-benar merender zone tersebut.

Shortcode Core

  • [post_cat_shortcode ...] untuk koleksi post.
  • [private_pdf id="123" mode="card"] untuk PDF dari File Library.
  • [video id="123"] untuk record video yang didukung.
  • [[widget:name key=value]] untuk widget terdaftar.

ID private file berasal dari menu Files, bukan Media Library. Pemeriksaan akses tetap berlaku ketika shortcode dirender atau stream diminta.

Preset

Preset adalah post bertipe sc_preset yang menyimpan konfigurasi query dan Collection Layout dalam JSON. Demo memasang dua preset published agar alur reuse dapat dilihat langsung di Shortcode Builder.

  • demo_random_posts menyimpan layout mini, yang dipakai tanpa override oleh widget sidebar Published Preset. Theme Section home.random-posts sengaja mendemonstrasikan override request-local menjadi grid dengan Limit 4, Max Items 20, dan pagination random ber-seed. Override ini hanya berlaku pada render beranda dan tidak mengubah konfigurasi Preset tersimpan. Tombol Acak Lagi membuang seed lama untuk membuat urutan baru.
  • demo_home_posts memakai layout cards, memilih artikel kategori Pengembangan secara deterministik, lalu dirender oleh Theme Section home.preset-posts pada homepage tema default.

Pemisahan tanggung jawabnya adalah: Preset memiliki query tersimpan dan memilih Collection Layout, Collection Layout hanya merender daftar post, sedangkan Theme Section menyediakan judul serta wrapper halaman yang reusable. PHP tepercaya dapat memberi override terbatas untuk satu pemanggilan tanpa memindahkan ownership atau mengubah Preset tersimpan. Dari daftar Presets, Site Owner dapat memakai aksi Build Section untuk membuat komposisi tanpa override dan tanpa menyalin query ke file tema.

Di renderer PHP tepercaya, gunakan render_shortcode_preset($pdo, 'demo_home_posts', [], $context). Di konten, preset tetap dapat digunakan sebagai [[widget:demo_home_posts]], sedangkan section dapat digunakan sebagai [[widget:theme_section name="home.preset-posts"]].

Plugin dapat mendaftarkan shortcode atau gadget tambahan. Validasi atribut, escape output, dan jangan memasukkan kode pihak ketiga yang tidak dipercaya ke HTML widget.
